KALKULADORA TETUN

Aplikasaun web ne'e bele funsiona iha iPhone no Android, no bele instala hanesan app (PWA).

Importante:
- Atu instala no uza offline, website tenke publika iha hosting ne'ebé uza HTTPS.
- Arquivu sira iha pasta ida ne'e.
- Upload kontéudu pasta ne'e ba hosting estátiku (ezemplu GitHub Pages, Netlify ka hosting seluk).
- Iha iPhone: loke website iha Safari > Share > Add to Home Screen.
- Iha Android: loke website iha Chrome > menu (⋮) > Install app ka Add to Home screen.

Nota: Ida ne'e protótipu kalkuladora. La publika ba App Store ka Google Play automaticamente.
